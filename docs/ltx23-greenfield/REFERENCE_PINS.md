# LTX 2.3 reference pins

The greenfield implementation must use these as reproducibility references:

- ComfyUI commit `12d5279438bfefc058a269eae805ceab6047777f` / `v0.34.0`
- `comfy-aimdo` `0.4.15`
- `comfy-kitchen` `0.2.31`
- The official pinned Comfy LTX 2.3 T2V, I2V, and FLF workflows
- The high-level upstream source-path index associated with those pinned
  workflows and release sources

Comfy is a behavioral and performance reference, not an Engine runtime
dependency. Narrow, attributed source adaptation is acceptable only where
licenses permit it. The deleted Engine implementation is not a reference.
