## Packet entry contract

A dispatched agent receives:

- one roadmap section and one operation/recipe key;
- accepted baseline pin and current research pin, separately labeled;
- exact raw workflow path and expected raw hash or a requirement to compute it before coding;
- publisher artifact/architecture sources;
- ComfyUI/Kitchen source ownership;
- Engine proof level and preserved accepted evidence;
- explicit files/modules likely touched, tests, hardware scenarios, exclusions, and stop conditions.

The agent must return the normalized upstream contract and independent fixtures before implementation changes. Green tests generated from the implementation are not evidence.

## Universal stop conditions

Stop and report evidence instead of improvising when:

- an immutable workflow, node source, artifact, license, or package pin cannot be resolved;
- active closure and disabled resources cannot be distinguished;
- output slot or media metadata is unknown;
- tensor mapping, sidecars, aliases, scales, or fixed LoRA targets are incomplete;
- Kitchen/native dispatch cannot be proven or falls back;
- the proposed request broadens official operation or input multiplicity without a separate Engine-extension recipe;
- cancellation leaves a worker, accelerator allocation, temporary output, or poisoned cache;
- a cataloged resource is being treated as runnable;
- dense Reference settings are being changed merely to fit local hardware.
