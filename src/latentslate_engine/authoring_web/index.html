1. Source inspection

Start here. Server inspection accepts Hugging Face and CivitAI sources, provides verified artifact facts and safe defaults, and does not publish anything.

Use a complete remote locator, for example hf://owner/repo/path/to/model.safetensors. A filename alone is not globally unique. Browser inspection cannot access local or NAS files; for those, use .\scripts\engine.ps1 resources inspect "<full-path>".
